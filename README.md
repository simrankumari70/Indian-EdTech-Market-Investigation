 # Indian EdTech Market Investigation

## Project Overview
This project investigates the Indian EdTech market using research, survey-related information, and regulatory sources.

## Objective
The objective of this project was to investigate the Indian EdTech market using research, survey, and regulatory data, focusing on adoption, technology, perceived benefits, risks, and consumer protection.

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables
- Power BI
- ChatGPT for research assistance and data organization

## Methodology
1. Collected and organized research information and source links.
2. Cleaned and organized data using Excel and Power Query.
3. Checked date formats, data types, text formatting, and column names.
4. Analyzed records using PivotTables.
5. Created a Power BI dashboard to present key findings.

## Dataset Overview
The working dataset contains 34 research records related to:
- EdTech adoption and usage
- Digital access and infrastructure
- Learning benefits and teacher experience
- AI and technology adoption
- Digital learning risks
- Advertising compliance and consumer protection

## Key Findings
The analysis identified the following research themes:
- Risk & Consumer Protection: 10 records
- Access & Infrastructure: 9 records
- Research Scope & Sample: 5 records
- EdTech Adoption & Usage: 5 records
- Benefits & Experience: 3 records
- AI & Technology: 2 records

Sentiment classification included 25 Neutral, 7 Positive, and 2 Negative records.

These findings describe the collected records and do not represent the entire Indian EdTech market.

## Project Files
- Dataset: Excel workbook with original and cleaned data
- Excel-Analysis: Analysis and PivotTables
- PowerBI: Power BI dashboard
- Screenshots: Excel and dashboard screenshots
- Report: Final project report in PDF format

## Limitations
The dataset contains a limited number of research records. Findings depend on the sources recorded in the workbook, and figures should be checked against the original publications.
